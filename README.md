# The Art of Nature Landscaping Website

A responsive, static HTML/CSS/JavaScript website suitable for GitHub Pages.

## Publish on GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. In the repository, select **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose **main** and **/(root)**, then save.

The site will become available at `https://USERNAME.github.io/REPOSITORY/` after deployment.
